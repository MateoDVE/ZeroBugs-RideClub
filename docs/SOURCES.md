## Recursos visuales

Fotografías y logos proceden de las páginas citadas y sus recursos públicos. Se usan para identificar las marcas y modelos en este prototipo de hackathon; los derechos pertenecen a sus titulares. Esto no acredita una licencia comercial ni una afiliación. Antes de un lanzamiento público comercial, confirmar autorización con las marcas y usar su kit aprobado.

`assets.json` registra cada URL original. Las fotos se conservan localmente para la demo; no se generaron imágenes de motos. Inter procede de Google Fonts y conserva su licencia SIL Open Font License en `frontend/public/assets/Inter-OFL.txt`.
